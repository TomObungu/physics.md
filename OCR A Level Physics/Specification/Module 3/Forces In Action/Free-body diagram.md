A free-body diagram shows all the forces acting on a particular object. The following forces are useful when drawing free-body diagram:

- thrust e.g. rod, car engines
- weight
- friction
- normal contact fore
- drag
- tension e.g, ropes, strings, wires,
- upthrust e.g. rocket engines, buoyant force.
