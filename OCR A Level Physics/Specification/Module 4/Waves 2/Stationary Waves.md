A stationary wave is the result of superposition of two progressive waves with the same frequency travelling in opposite directions. 
Figure 1 shows a stationary wave on a stretched string with three 'loops'. The profile of the string is the result of the superposition of progressive waves travelling to the left and to the right. The progressive and stationary waves have the same period $T$ and frequency $f$.

- A stationary wave had nodes and antinodes. A node is a point that Zero amplitude and a node is a point of maximum amplitude. 
- Seperation between adjacent nodes or antinode is $\frac{\lambda}{2}$.
- Seperation between a node and an antinode is $\frac{\lambda}{4}$.
- The speed $v$ of the progressive wave $v=vf$. This can also be applied when the stationary wave is at it's fundamental frequency $f_{0}$. 

## Differences between progressive and stationary waves

|                  | Progressive Wave                 | Stationary                                                      |
| ---------------- | -------------------------------- | --------------------------------------------------------------- |
| Energy transfer  | Yes                              | No                                                              |
| Frequency        | The same for all points          | The same for all points except for nodes                        |
| Amplitude        | The same for all points          | Varies from zero at the nodes and to maximum at antinodes       |
| Phase Difference | $\phi = \frac{x}{\lambda}(2\pi)$ | $\phi = \pi n$, where $n$ is the number of nodes between points |
## Forming stationary waves using microwaves
A stationary wave can be formed by reflecting microwaves off a metal sheet so that two microwaves of the same frequency are travelling in opposite directions. A microwave receiver detects a series of nodes and antinodes. The distance between sucessive nodes or antinodes is $\frac{\lambda}{2}$.
