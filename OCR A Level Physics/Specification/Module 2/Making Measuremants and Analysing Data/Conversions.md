When converting units of area or volume, you must apply the conversion factor to _every_ dimension. The easiest way to remember this is to treat the prefix as a number inside a set of parentheses.

# The general rule
If a linear conversion is $1cm = 10^{-2}m$, then:
- Area ($^{2}$) : ($10^{-2}$)$^{2}$ = $10^{-4}$
- Volume ($^{3}$) = (10$^{-2}$)$^{3}$ = $10^{-5}$

 In general, the conversion factor for a derived unit is the linear conversion factor raised to the same power as the unit.

Formally, if the linear scale factor between two units is $k$, then:
- The area scale factor is $k^{2}$
- The volume scale factor is $k^{3}$.
