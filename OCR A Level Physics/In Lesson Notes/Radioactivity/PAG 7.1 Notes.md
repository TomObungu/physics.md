# Aim
- To obtain evidence to support the random nature of radioactive decay
# Equipment
- Radioactive object such as thoriated welding rod
- Geiger-Muller (GM) tube
- Counter
# Safety
If using a thoriated welding rod, do not abrade or cut the rod. 

# Method
1. Set up the GM such that it is vertical 
2. Connect the GM tube to the counter and select a 10 second count time.
3. Before taking readings take a reading of the background count rate
4. Place the radioactive object immediately above the GM tube using long-handled tongs.
5. Take ten separate readings of the ten second count time. When recording readings, subtract the background count from the recorded value to produce a corrected count rate
6. Find the mean count for each reading and repeat the procedure twice more. 
# Calculations 
- Draw a table of corrected count rate against time. 
- Plot a graph of corrected count rate against time and draw a line of best fit. In this case it will be a curve
- The line of best fit should match an exponential graph with a rapidly decreasing gradient. The time taken for this graph to halve to halve should be constant and the name of the this constant time is the half life $t_{\frac{1}{2}}$. 
# Safety 
- Never directly handle the source, use long-handled tongs
- Store the source in a lead-lined container when not in use
- Never point the source at others
